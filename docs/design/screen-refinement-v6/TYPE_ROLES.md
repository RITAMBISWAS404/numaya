# Typography, V6

Approved families and the 15 logical pixel body are unchanged. Every weight goes through the variable `wght` axis, so none are synthetic.

| Role | Use | Colour |
|---|---|---|
| Primary | Titles, row labels, values | #000000 |
| Secondary | Descriptions, helper text | #666666, 5.74:1 on white |
| Supporting metadata | 12/16 captions | #666666 |
| Disabled | Inactive controls only | #8A8A8A, exempt from contrast rules |

Change made: `hero` is bold (700), so names on photos hold up. The other audited roles needed no change. Heading weight options are in the gallery as `v6-page-title`.

System text scale is never clamped. Long labels were checked at 1.5 and 2.0 on the 11 stress screens.

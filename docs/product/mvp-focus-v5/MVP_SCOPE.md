# MVP Focus V5 scope

This is the active product scope. The Events PRD (`docs/product/events-mvp/`) remains a deferred roadmap.

**In scope:** Discover left and right swipe, filters, profile detail, Compliments, matches, Messages, chat, archive, profile and onboarding, streaks, wallet and credit simulation, Premium simulation, settings, report, block, unmatch, delete account.

**Deferred:** Events, Health and Insights. See [SCOPE_DELTA.md](SCOPE_DELTA.md).

**Rules unchanged by this pass:** like and Compliment limits, streak awards, wallet, Premium plans and timer policies. Compliment behaviour is in [COMPLIMENT_CONTRACT.md](COMPLIMENT_CONTRACT.md).

This is a front-end candidate. See [LAUNCH_READINESS.md](LAUNCH_READINESS.md).

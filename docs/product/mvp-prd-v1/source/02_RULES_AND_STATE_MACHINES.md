# Authoritative rules
Server UTC timestamps; India daily reset midnight Asia/Kolkata, shown locally. Weekly free extensions reset Monday IST. Premium weekly credits anchored to subscription activation, independent of monthly/yearly billing. All clocks server-controlled; timers rendered from timestamps.
Like unique(sender,recipient): idempotent; quota debit and mutual-match creation atomic. Duplicate taps do not spend twice. Already blocked/ineligible/deleted accounts cannot receive likes. Declined profiles stay excluded until explicit future reconsideration feature; no recycling to imply new supply.
Match states awaiting_first_message -> active -> expired -> reconnect_pending -> active; blocked/unmatched terminate. First message at deadline succeeds only when authoritative acceptance precedes expiry. Any genuine accepted chat message resets quiet timer; system notices do not. Both users notified once at seven days, optional feedback; no response does not affect score/ranking. A second one-sided message may reset timer, so rate-limit spam and provide mute/block; monitor this policy during pilot.
Reconnection one request per pair per expiry episode, one outstanding; after rejection no repeat for that episode. Acceptance opens chat; no auto-message or charge. Unmatch is distinct and cannot be reversed through reconnection.
Compliment one lifetime introduction per unordered pair for MVP; no retry after dismissal. Deleted referenced photo/prompt shows unavailable reference; content change never retargets message. Block hides all requests. Reply is free and transactional. A simultaneous mutual like converts request to the same conversation, never duplicates.
Ledger append-only: grant, spend, expiry, reversal; idempotency key and source identifiers mandatory. Weekly expiry touches weekly balance only. Refunds reconcile purchased entitlement without deleting conversation history. Subscription cancellation retains entitlement through paid-through date; expiry removes advanced controls but preserves preferences for later use, executes only free filters.
Streak based on accepted server events on distinct local days. Recovery repairs a missing day only if it joins an eligible sequence; no purchase on outages caused by Numaya, restore automatically. Show deadline, resulting streak and price before purchase. Never charge if server no longer permits repair. Award unique(user,cycle); cap applied once.
Privacy/safety overrides every paid entitlement. Suspended users receive free reason/appeal path where appropriate; no reveal of reporter identity. Pause hides new discovery but preserves existing chats and credits. Delete removes discovery immediately and follows documented deletion/retention schedule.

# Monochrome Meetup: design experiment

**What it is:** an experimental visual identity for the native Flutter app, on
`experiment/numaya-monochrome-meetup`:
- monochromatic and spacious;
- rounded, with Numaya's purple;
- led by Meetup, with Jomo, Bevel and Alan as supporting references.

The baseline is unchanged on `experiment/numaya-overnight-completion`.

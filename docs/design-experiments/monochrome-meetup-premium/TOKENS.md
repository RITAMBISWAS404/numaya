## Elevation
**Flat by default.**

| Token | Use |
|---|---|
| `subtle` | 2/1 + 12/4 at 3–4% ink: the tab pill |
| `floating` | 4/1 + 24/8 at 6–8% ink: the RSVP bar, toasts |
| `segment` | Selected segment |
| `thumb` | Switch and slider thumbs |

No other shadows; no glow; no gradient.

## Contrast (computed, WCAG 2.x relative luminance)
**Generated by:** `python3 evidence/contrast_check.py`, which reproduces this table.

**Scope:** the pairs listed are the ones the screens actually render. Unit tests in
`test/unit/foundation_test.dart` enforce the same thresholds, so a token change that breaks a pair
fails `flutter test`.

**Thresholds:** text needs 4.5:1. Non-text marks need 3:1. Disabled controls are exempt under
WCAG 1.4.3.
